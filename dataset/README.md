# Dataset

Real, locally-generated data — not fabricated numbers, not a real exploit-chain dataset.
See the honesty note below before using this for anything beyond what it actually is.

## What's here

- `benign/local-benign-traces.jsonl` — 40 real captured traces (20 process-execution +
  20 deserialization), generated by calling real sinks from a trusted caller
- `malicious/local-malicious-shaped-traces.jsonl` — 40 real captured traces (20 + 20),
  generated by calling the same sinks from a caller deliberately absent from
  `provguard.enforcement.Policy`'s trusted allowlist

Both were generated by actually running `provguard.tools.DatasetGenerator` against the
real live agent — every `depth`/`edgeCount`/`caller` value in these files is a genuine
`StackWalker` capture, not invented.

## Format

One JSON object per line (JSON Lines):
```json
{"timestamp":"2026-09-02T22:17:59.511449800Z","sinkType":"PROCESS_EXECUTION","label":"benign","depth":3,"edgeCount":2,"caller":"provguard.tools.DatasetGenerator"}
```

| Field | Meaning |
|---|---|
| `timestamp` | Real capture time (ISO-8601) |
| `sinkType` | `PROCESS_EXECUTION` or `DESERIALIZATION` |
| `label` | `benign` or `malicious_shaped_local_synthetic` (see honesty note) |
| `depth` | Number of call-stack frames captured (`ProvenanceGraph#depth()`) |
| `edgeCount` | Number of graph edges (`ProvenanceGraph#edges().size()`) |
| `caller` | The class `ProvenanceGraph#callerClassName()` identified, or `null` |

## HONESTY NOTE — read before using this for anything

The `malicious_shaped_local_synthetic` label means exactly what it says: these traces
come from a caller not on the trusted allowlist, structurally similar to the benign
traces (same sink, similar depth — see the actual numbers above; malicious depth is 4 vs.
benign depth 3, because the untrusted caller path goes through one extra method call, a
real structural artifact, not an injected difference). **This is NOT a real exploit
chain.** No `ysoserial`, `GCMiner`, `JNDI-Injection-Exploit-Plus`, or any other real
gadget-chain/payload generator is used or bundled anywhere in this project. This dataset
is useful for exercising `AllowlistDetector` (which cares about caller identity) and for
`OneClassDistanceDetector`'s structural-feature approach in a limited way, but it is
**not** a substitute for the real labeled benign/malicious trace dataset the original
ProvGuard research plan calls for (which would require integrating actual exploit-payload
generators against real vulnerable local fixtures — not done, see `docs/DATASET.md` and
`docs/EVALUATION.md`).

## Regenerating

```
mvn package
java -javaagent:target/provguard-agent.jar -cp target/provguard-agent.jar provguard.tools.DatasetGenerator
```
Source: `src/main/java/provguard/tools/DatasetGenerator.java`.
